# `render-html-document`

Render existing Markdown engineering artifacts as polished, self-contained, navigable HTML while keeping the Markdown source authoritative.

Typical uses include design documents, speaker notes, and long-form engineering reports. The renderer owns presentation and navigation, not semantic rewriting.

```text
Use render-html-document on design-doc.md and speaker-notes.md.
```

The resulting HTML should be suitable for local reading, sharing, rehearsal, and printing without requiring a separate build step.

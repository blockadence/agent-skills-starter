# `bbp-story-plan`

Plan a Beyond Bullet Points (BBP) style engineering presentation from an explanatory model. Use for visual-first technical presentations where the audience must encounter the topic and pain before the solution, with progressive disclosure and speaker notes that form a rehearsal script.

## Contract

`SKILL.md` is the executable agent contract. This README is human-facing orientation only. The skill follows the repository composition rules in `CLAUDE.md`: user instructions take precedence, producer semantics and structure come next, and compatible modifiers apply without changing technical truth.

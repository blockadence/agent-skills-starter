# `visual-render-audit`

Audit rendered engineering diagrams for geometry and readability. Use after rendering C4, UML, ER, sequence, state, activity, deployment, or custom explanatory visuals to catch edge-label collisions, text crossings, ambiguous containment, bad wrapping, poor scan direction, and loss of canonical recognizability.

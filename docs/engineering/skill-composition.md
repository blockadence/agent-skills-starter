# Skill composition

Producing skills own substance, structure, evidence, and output contracts.
Modifier skills such as `in-my-voice` own compatible expression constraints.

Apply modifiers during generation, not as blind post-processing rewrites.

Example:

```text
/to-design-doc work/schema-registry/understanding.md work/schema-registry/design-template.md
Apply in-my-voice.
```

For `to-design-doc`, source-specific guidance in `understanding.md` under
`How to present it` is more specific than a general voice modifier and therefore
specializes it.
